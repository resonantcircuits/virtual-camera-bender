How Virtual Camera Bender Works

The Signal Path

Camera preset → Effect modules → Image.

Cameras are starting points, not limits. Clicking one copies its full settings into the editor. From there everything is yours: every slider, randomizer, and module works from the current state, no matter which camera you started with.

The Gallery (button above the Camera Presets list, or G) shows every camera rendered live on your loaded image, side by side. Click a card to load that camera.

The Module Panels

Sensor Effects simulates real bend circuitry acting on the raw sensor signal (oscillators into the analog path, logic chips on the ADC data bus). It runs before everything else and changes through its own controls, camera presets, the Physics randomize button, its dice button, and the hardware-led share of New Random Camera rolls.

Image Effects is where the damage look is built: one module per effect, every parameter exposed. Hover a parameter for a short description of what it changes.

Classic Adjustments is ordinary photo editing after the camera damage is complete: brightness, contrast, saturation, color temperature, and tone cleanup. Randomize leaves it alone.

Each module header has six controls. The lamp on the left switches the module on or off — and changing any parameter inside a module switches it on automatically. Hover a module name for a one-line description of what it does. On the right: the lock freezes that module during randomize, the dice re-rolls just that module, the reset arrow restores its defaults, the eye solos it so you see only its effect, and i opens the module’s full notes.

ALL OFF switches off every module in a panel. RESET ALL restores every module in that panel to defaults. The Reset All Modules button above the panels does both everywhere at once — a clean slate showing the untouched image.

Randomize

New Random Camera starts a fresh damage chain. The smaller refinement buttons work from the current camera and replace only one kind of damage.

Intensity sets how hard it hits: Gentle lightly bends a still-readable photograph, Broken strongly distorts sections while retaining the general scene, and Wrecked builds an abstract image from the source. Explore draws one coherent result from that entire range. The per-module dice use this intensity too.

New Random Camera clears the previous damage and composes a whole new camera around a randomly selected character (new name, seed, active modules, and parameters). The eight refinement buttons (Physics, Color, Melt, Burn, Noise, Cheap, Shift, Corrupt) rebuild only their named damage type. They keep every other module and the current render seed fixed, so they are safe ways to refine a promising camera.

Locked modules in the right-side panels are restored after randomize, including whether they are enabled. Pressing a locked module's dice does nothing and flashes the lock. Locks are session-only and are not saved into camera files.

Seed

The seed steers every random pattern in the render: noise grain, drip positions, block glitches. Reroll keeps all your settings but redraws the damage in new places. Family and module refinements keep it fixed; the lock also makes New Random Camera keep it. Same settings + same seed = same image.

The seed lock holds the current seed during Randomize. Manual Reroll still changes the seed on purpose. Seed lock is session-only and is not saved into camera files.

Comparing

Split A/B overlays the original left of a divider you drag across the image. Hold · Original (or holding C) flashes the untouched photo.

Mouse wheel zooms the preview image. When zoomed, drag the image to pan and double-click to reset the view.

Export

Format chooses PNG, WebP, or JPEG. Size chooses what gets written.

Preview exports the same scaled render shown in the UI, capped at 1500 px on the longest edge. This is the default because resolution-dependent effects like contour rings, noise, sorting, and OSD match what you see.

Full re-renders the original source resolution. It can take longer, make larger files, and look denser because many effects are intentionally resolution-dependent.

Supported browsers open a save dialog for filename and location. Others ask for a filename and then use the browser's normal download folder.

Video

Loading a video opens the Frames contact sheet (V): 25 evenly spaced frames rendered through the current camera. Click a frame to make it the working image — every editor tool then works on that frame exactly as it will render in the final video.

The Temporal panel controls behavior across frames. Seed Mode: locked keeps all damage frozen in place, hold re-rolls it every ~N frames (camcorder stutter), flicker re-rolls every frame. Sensor grain and speckle always shimmer per frame regardless — only the structural damage obeys the mode. Drift makes module parameters wander slowly so the look evolves. Ghost Lag feeds the Buffer Ghost module the frame N back — real stale-buffer trails (enable Buffer Ghost to see it).

The app never encodes video. Copy Render Command gives you an OS-formatted CLI line with the current camera embedded, so no camera file is needed. Choose Smaller File, Balanced, or High Quality before copying, then run it with ffmpeg installed.

Saved Cameras and Session State

Save Camera asks for a name and notes, then writes camera settings, seed, module parameters, output format, and export size. It does not save the source photo, ghost source image, module locks, seed lock, undo history, or split/solo view state.

Buffer Ghost can use a loaded second image as the stale frame. If no ghost image is loaded, it falls back to the current image.
